🚩 Common mistake: checking the position of @ with .find() before confirming there’s exactly one @ in the first place. .find() only ever returns the first occurrence – if you skip the .count("@") == 1 check, an address like "a@b@c.com" (two @ symbols) can slip through as if it were valid.

Problem 4: Content Filter#

Create a content filtering system that analyzes text. This version uses NO LOOPS – you’ll use the techniques from Class 3.

Budget extra time for this one – it’s the longest problem. You’ll check each word individually with separate Boolean variables. Once you learn loops, you’ll see how to write this in about 10 lines instead of 100!

See the reading’s Comparing to Boolean Values section – the starter code below deliberately writes comparisons like (hasViolence == True), which is exactly the pattern that section discusses.

# Get text input
userText = input("Enter text to analyze: ")
targetAudience = input("Target audience (child/teen/adult): ").lower()

# Basic text analysis using string methods
textLength = len(userText)
wordList = userText.split()
wordCount = len(wordList)
sentenceCount = userText.count(".") + userText.count("!") + userText.count("?")

# Text complexity analysis
hasLongText = (textLength > 500)
hasManyWords = (wordCount > 100)
hasManySentences = (sentenceCount > 10)

# Check for inappropriate content - NO LOOPS!
# We'll check each word individually using the technique from Class 3
lowerText = userText.lower()

hasViolence = ("violence" in lowerText)
hasHate = ("hate" in lowerText)
hasInappropriate = ("inappropriate" in lowerText)
hasBad = ("bad" in lowerText)

# Combine with OR (if ANY inappropriate word is found)
hasInappropriateContent = (hasViolence == True) or (hasHate == True) or (hasInappropriate == True) or (hasBad == True)

# Build list of found inappropriate words
foundInappropriateWords = []
if hasViolence == True:
    foundInappropriateWords.append("violence")
if hasHate == True:
    foundInappropriateWords.append("hate")
if hasInappropriate == True:
    foundInappropriateWords.append("inappropriate")
if hasBad == True:
    foundInappropriateWords.append("bad")

# Check for positive content - NO LOOPS!
hasGreat = ("great" in lowerText)
hasAwesome = ("awesome" in lowerText)
hasWonderful = ("wonderful" in lowerText)
hasExcellent = ("excellent" in lowerText)
hasAmazing = ("amazing" in lowerText)

# Combine with OR
hasPositiveContent = (hasGreat == True) or (hasAwesome == True) or (hasWonderful == True) or (hasExcellent == True) or (hasAmazing == True)

# Build list of found positive words
foundPositiveWords = []
if hasGreat == True:
    foundPositiveWords.append("great")
if hasAwesome == True:
    foundPositiveWords.append("awesome")
if hasWonderful == True:
    foundPositiveWords.append("wonderful")
if hasExcellent == True:
    foundPositiveWords.append("excellent")
if hasAmazing == True:
    foundPositiveWords.append("amazing")

# Age-appropriate analysis using explicit Boolean comparisons
isAppropriateForChildren = (hasInappropriateContent == False) and (textLength <= 200) and (hasManyWords == False)
isAppropriateForTeens = (hasInappropriateContent == False) and (textLength <= 1000)
isAppropriateForAdults = True  # Adults can read anything

# Content rating based on target audience
isContentApproved = False
if (targetAudience == "child") and (isAppropriateForChildren == True):
    isContentApproved = True
elif (targetAudience == "teen") and (isAppropriateForTeens == True):
    isContentApproved = True
elif targetAudience == "adult":
    isContentApproved = True

# Reading level analysis
if sentenceCount > 0:
    averageWordsPerSentence = wordCount / sentenceCount
else:
    averageWordsPerSentence = 0

print (f"is the content approved? {isContentApproved}")

Problem 5: Membership Discount Calculator#

Write a Python program that calculates the final price of a purchase based on the total amount and the customer’s membership status.

See the reading’s If-else Statements section for a refresher.

Your program should:

  1. Prompt the user to enter:

    • The total purchase amount (a number, e.g., 120.50)

    • Membership status as a string: "Gold", "Silver", or "None"

  2. Apply discounts based on the membership and purchase amount:

    • Gold members:

      • 15% discount for purchases under $100

      • 20% discount for purchases of $100 or more

    • Silver members:

      • 5% discount for purchases under $100

      • 10% discount for purchases of $100 or more

    • No membership:

      • No discount

  3. Calculate and print:

    • The original total amount

    • The discount applied

    • The final price after discount

  4. Use nested if statements to handle the different membership levels and purchase amount thresholds.

  5. Format all monetary values as dollars and cents ($dd.cc).

  6. Comment your code appropriately to explain your logic.

Example run (Gold member, purchase >= $100):

Enter total purchase amount: 150
Enter membership status (Gold/Silver/None): Gold
Total amount: $150.00
Discount: $30.00
Final price: $120.00

Example run (Silver member, purchase < $100):

Enter total purchase amount: 80
Enter membership status (Gold/Silver/None): Silver
Total amount: $80.00
Discount: $4.00
Final price: $76.00

Example run (No membership):

Enter total purchase amount: 120
Enter membership status (Gold/Silver/None): None
Total amount: $120.00
Discount: $0.00
Final price: $120.00

🚩 Common mistake: nesting the amount check as the outer condition and the membership check as the inner one (or vice versa) without thinking through which one should drive the structure. Since the discount percentage depends on both membership level and amount, and the two membership levels have completely different rates, it’s clearer to check membership first (outer if/elif/else for Gold/Silver/None), then nest the amount threshold inside each branch – not the other way around.

Stage 7.5: Refactor with elif#

At this point, you have a deeply nested program that’s hard to read!

Now refactor:

  2. Test with several combinations of inputs (light, pedestrian, emergency) to confirm the programs behave the same.

Notice: The elif version should be flatter and easier to understand!

🚩 Common mistake: when flattening deep nesting into elif, it’s easy to accidentally change which condition wins when several are true at once – e.g. an emergency vehicle present at a red light with the pedestrian button pressed. Check your elif chain’s order, not just that each individual branch looks right in isolation: whichever condition comes first in the chain is the one that fires, even if a later condition would also be true.

light = input("Traffic light color (green/yellow/red): ").strip().lower()
