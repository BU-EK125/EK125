Problem 1.1 Exploring the range function#

  1. Create a variable called myr that stores the sequence produced by range(6).

  2. Convert myr into a list and print it.

  3. Finally, use the len function to print the number of elements in the list.

Your output should clearly show both the list of numbers and its length.

Hints

  • The range(n) function generates numbers starting at 0 and ending just before n.

  • range by itself doesn’t immediately display as a list of numbers — think about how you can convert it into a list.

from random import randint

Problem 1.7: Running products#

A running product is the product of numbers. A running sum is initialized to 0, so the first time something is added to it, it does not change. A running product, on the other hand, is initialized to 1. The following should calculate a running product of the integers from 1 to 5.

Identify what is wrong and write code that fixes it.

runprod = 1
for i in range(6):
   runprod = runprod * i
   print('The product so far is', runprod)

runprod = 1
for i in range(5):
    runprod = runprod * (i+1)
    print('The product so far is', runprod)

The product so far is 2

The product so far is 24
The product so far is 120

  • Prompts the user to enter a radius (as a float)

  • Calculates the circumference using the formula: circumference = 2 × π × radius

  • Prints both values rounded to 2 decimal places

To access the constant π (pi), use:

from math import pi

Problem 2.1: A while loop that might not run#

Here is an example while loop:

# Example: a loop that runs
count = 5
while count > 0:
    print("Counting down:", count)
    count = count - 1
print("Done!")

When you run this code, you should see:

Counting down: 5
Counting down: 4
Counting down: 3
Counting down: 2
Counting down: 1
Done!

In this example, the condition count > 0 is True when the loop starts, so the body of the loop runs several times before stopping.

  • Write code with an initial value for count that makes the loop body run exactly once?

  • Write code with an initial value for count that makes the loop body never run at all?

# Case 1: Loop body runs exactly once
count = 1
while count > 0:
    print("Counting down:", count)
    count = count - 1
print("Done!")

Counting down: 1
Done!

# Case 2: Loop body never runs
count = 0
while count > 0:
    print("Counting down:", count)
    count = count - 1
print("Done!")

Done!

Problem 2.3: While Loops — Counting and Averages#

Ahead of time, we do not know how many times the action of a while loop will be executed. However, it is frequently useful to count the number of times that the action has been executed.

Write a script that:

  • Prompts the user to enter positive numbers, one at a time.

  • Continues until the user enters a negative number.

  • Keeps track of both:

    • The sum of the positive numbers entered.

    • The count of how many numbers were entered.

  • At the end:

    • If no positive numbers were entered, print an error message.

    • Otherwise, print the average of the positive numbers.

    • Also print how many tries it took, in the form:

      It took xx tries.

    • If the user stops the loop after the very first input, print:

      It took 1 try.

# Initialize variables
total = 0
count = 0

# Prompt for the first number
num = float(input("Enter a positive number (or a negative number to stop): "))

# Loop while the number is positive
while num >= 0:
    total += num
    count += 1
    num = float(input("Enter a positive number (or a negative number to stop): "))

# After the loop
if count == 0:
    print("Error: no positive numbers were entered.")
else:
    average = total / count
    print(f"The average of the {count} numbers is {average:.2f}")
    if count == 1:
        print("It took 1 try.")
    else:
        print(f"It took {count} tries.")

Enter a positive number (or a negative number to stop): 4
Enter a positive number (or a negative number to stop): 8
Enter a positive number (or a negative number to stop): 15
Enter a positive number (or a negative number to stop): -1
The average of the 3 numbers is 9.00
It took 3 tries.

Problem 2.4 Error checking#

Error-checking is an important application of while loops. Whenever the user is asked for input, there is almost always a valid range of values. When prompted, the code should loop until the user enters a valid value.

Write code that will prompt the user for a number in the range from 1 to 10. Tthe code will keep prompting as long as the user is not entering a number in the valid range, meaning that as long as the user is entering a number that is either less than 1 or greater than 10. So, there will be two parts to the condition (so remember your logicals!)

mynum = float(input('Enter a number between 1 and 10: '))
while mynum < 1 or mynum > 10:
    mynum = float(input('Seriously, enter a number between 1 and 10: '))
print(f'Thanks! You entered {mynum:.1f}.')

Enter a number between 1 and 10: 15
Seriously, enter a number between 1 and 10: 7
Thanks! You entered 7.0.

Write code that will present the user with choices for functions:

  • 1 for doubling the number

Error-check by looping to display the choices until the user enters 1, 2, or 3. Then, generate a random real number between 0 and 1, and print the result of the user’s chosen function on that number.

Hint: To generate random real numbers between 0 and 1, you will need a special function from the random library, which is confusingly also called random(). Be sure to import the random() from from the random library using the same synatx as abvoe. Use help() to get some information about how random() works!

print("Please choose a function:")
