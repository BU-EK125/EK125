Homework 8: Plotting in Python and MATLAB, Vectors and Matrices#

This homework has two halves, worth 50 points each, covering Class 21, Class 22, and Class 23. You must complete each half in its own downloaded file – not on this web page. This page’s instructions mirror what’s in the files so you can read them without switching windows, but the downloaded files are what you edit, run, and submit.

Download the Assignment Files#

Download: HW8_python.py and HW8_matlab.m

Due Tuesday, November 24, 11:59 PM. Submit to Gradescope:

  • HW8_python.py, stress_strain_python.png, turbine_dashboard.png, section_averages.png

  • HW8_matlab.m, stress_strain_matlab.png, sensor_rows.png, rectifier.png

Instructions#

  • Individual work.

  • Use good programming practice: comments, meaningful variable names, consistent indentation.

  • No global variables, no break/continue, no while True/while true loops – any of these is an automatic zero for that problem.

  • Every figure needs an x-axis label with units, a y-axis label with units, a title, and a legend whenever there’s more than one data series.

  • Python: before you start, make sure matplotlib is installed in your PyCharm project (Python Packages tool window, or pip install matplotlib in the Terminal). Save every figure with plt.savefig(..., dpi=300, bbox_inches='tight') before plt.show() is called.

  • MATLAB: end lines with a semicolon unless a problem tells you to display the result. Use the provided %% section breaks to run one problem at a time with “Run Section”. Save every figure with saveas(gcf, 'filename.png').
