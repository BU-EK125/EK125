Homework 2: Strings and Lists#

This assignment covers material from Class 2: string operations, list manipulation, and basic data processing.

Run ALL code cells before submitting, use good programming practices, and match the output format exactly as shown in the examples for each problem.

It’s important to be consistent with code formatting and patterns because consistency makes it much easier for a human to move around a code base fluidly and effectively, without having to adjust to different formatting patterns as they go.

To that end, these are the patterns we’d like you to use:

  • No global variables – these are too broad in scope and make bugs due to unintended state mutation much more likely.

  • Use snake_case for variable names, not camelCase – the widely adopted Python standard.

Estimated time: 1.5-2 hours total. Start early and take breaks!

Problem 1: Personal Information Processor#

Write a program that processes personal information stored as strings and lists.

See the reading’s Common String Operations and Modifying Lists sections for a refresher.

🚩 Common mistake: list.sort() sorts the list in place and returns None – writing hobbies = hobbies.sort() throws away your whole list, replacing it with None. Call hobbies.sort() on its own line, then use hobbies afterward; don’t reassign it from the call.

Expected Output:

First name: Jane
Middle name: Marie
Last name: Smith
Initials: J.M.S.
Updated hobbies: ['coding', 'cooking', 'photography', 'reading', 'swimming']
Username: jane.smith

# 3. Add "coding" to the hobbies list
# 4. Print the hobbies in alphabetical order (look up the sort() method)
# 5. Extract the username from the email (part before @)
